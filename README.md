# Грабелька

Учебный MVP агрегатора фермерских продуктов Санкт-Петербурга и Ленобласти. Покупатель заказывает у одного фермера за раз, фермер сам привозит заказ и платит сервису 20% с проданного.

## Как устроено

- `index.html` — всё приложение: каталог, карточка товара, корзина, тестовая оплата, кабинет фермера, проверка ферм.
- `config.js` — где хранить данные: без базы, Google Таблица или Supabase.
- `google-sheets/Code.gs` — скрипт, который превращает Google Таблицу в базу.
- `supabase/schema.sql` — таблицы и правила доступа для Supabase.

Сайт отдаёт GitHub Pages, данные хранит Google Таблица или Supabase. Без настроек в `config.js` сайт работает как демонстрация: при первом открытии появляются примеры ферм и товаров, а заказы и новые товары сохраняются только в браузере посетителя. Для показа на встречах Supabase не нужен, достаточно шага 4.

## Запуск с Google Таблицей

1. Создать Google Таблицу, открыть Расширения → Apps Script, вставить `google-sheets/Code.gs`, поменять `ADMIN_KEY`.
2. Выбрать функцию `setup` → «Выполнить» → разрешить доступ к таблице и Диску.
3. «Начать развертывание» → «Новое развертывание» → «Веб-приложение», запуск от имени «Я», доступ «Все». Скопировать URL `.../exec`.
4. В `config.js`: `backend: 'sheets'`, `sheetsUrl: '<URL>'`.
5. На сайте: Профиль → «Вход для команды» с паролем `ADMIN_KEY` → «Загрузить примеры ферм».

Цветные столбцы таблицы (цена, статус, название) можно править вручную, сайт подхватит изменения примерно за 15 секунд. Фото товаров сохраняются в папку «Грабелька — фото» на Google Диске.

Ограничения: защита условная (любой знающий адрес скрипта может записать данные), обновление раз в 15 секунд, настоящие персональные данные не хранить.

## Запуск с Supabase

1. Supabase → SQL Editor: выполнить `supabase/schema.sql`.
2. Supabase → Authentication → Sign In / Providers: включить **Allow anonymous sign-ins**.
3. Вписать Project URL и anon public key в `config.js`.
4. GitHub → Settings → Pages: Source «Deploy from a branch», ветка `main`, папка `/ (root)`.
5. Открыть сайт, в «Профиле» скопировать «Ваш ID» и выполнить в SQL Editor:
   `insert into public.admins (uid) values ('<ваш id>');`
   После этого появятся «Проверка ферм» и кнопка «Загрузить примеры ферм».

## Ограничения

- Оплата тестовая, деньги не списываются.
- Вход анонимный: если очистить браузер, профиль фермера на этом устройстве потеряется.
- Персональные данные (имена, телефоны, адреса) по 152-ФЗ для настоящего запуска нужно хранить на серверах в России.
